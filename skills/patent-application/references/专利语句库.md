# 专利语句库（撰写可直接复用的句式 / 词库 / 附图标记规范）

> 来源：CNIPA 发明公布文本风格（CN122949635A/CN120083446A/CN122987292A 等 5 篇）+ 任务流程沉淀。
> 用法：撰写说明书/权利要求书/摘要时，按用途直接复制改写，保证公布文本风格一致。
> 配套：`撰写任务流程.md`（章节-意图-核心句-逻辑）、`公布文本风格指南.md`（各章句式模板）、`5篇公布文本风格总结.md`（案例）。

---

## 一、句式库（按用途）

| 用途 | 句式 |
|------|------|
| 领域句 | 本发明属于{领域}技术领域，具体涉及一种{方案对象}。 |
| 背景引 | 在{领域}，{对象}是{现象}。当前，对于{对象}已有较多研究…。例如，采用{方法}的方法…。又例如，采用{方法2}…。 |
| 不足推进 | 然而，现有的{对象}…仍存在诸多不足：首先，…；其次，…；再次，…。上述缺陷导致难以实现{目标}，{后果}。 |
| 目的句 | 本发明的目的在于针对上述现有技术中的问题，提供一种{方案对象}，通过{关键手段}。 |
| 方案引导 | 为了实现上述目的，本发明有如下的技术方案： |
| 分方面 | 第一方面，提供一种{方法}，包括：…；第二方面，提供一种{系统}，包括：…。 |
| 优选 | 作为一种优选的方案，…。 |
| 效果 | 相较于现有技术，本发明至少具有如下的有益效果：…。 |
| 附图引 | 为了更加清楚地说明本发明实施例的技术方案，下面将对实施例中所需要使用的附图作以简单地介绍…。 |
| 实施引 | 下面将结合本发明实施例中的附图，对…技术方案进行清楚、完整地描述…。 |
| 实施变体 | 在一种可能的实施方式中，步骤S1所述…。进一步的，步骤S3…具体包括：…。 |
| 收尾 | 最后应当说明的是：以上实施例仅用以说明本发明的技术方案而非对其限制…均应涵盖在本发明的权利要求保护范围之内。 |

## 二、功能词 / 动词库

- **功能词**：所述、用于、预设的、根据…确定、包括、其特征在于、配置为、被配置为、至少一种、任意一种或多种的组合。
- **动作动词**：获取/采集、计算、比对/比较、确定、输出、映射、联动、判定、施加、修正、提取、归入、合成。
- **避免词**：能够/可以/有效/显著/性能优异/发明人认为/经检索/数据库名/URL（效果放说明书）；"中国专利申请CNxxx公开了"（背景叙述化）。

## 三、附图标记规范（黑白线条）

- **图一律黑白**：线条+文字，无彩色/灰度/阴影；区分用线型/线宽/图案填充。
- **图号**：图1、图2…按出现顺序，写在说明书「附图说明」与插图下方正文，**不画进图内**。
- **图名**：`本发明实施例{图名}示意图`。
- **件号**：结构图用（10）（20）…，与说明书同一张表；框图/流程图不标件号、不拉引出线。
- **摘要附图**：主流程图（或主图）。

## 四、类型-章节-内容-图对应

| 专利类型 | 章节 | 内容 | 配图 |
|----------|------|------|------|
| 发明（方法） | 发明内容/具体实施 | 方法步骤 | 流程图 |
| 发明（系统） | 发明内容/具体实施 | 系统模块 | 架构图 |
| 发明（方法+系统） | 发明内容/具体实施 | 步骤+模块 | 流程图+架构图 |
| 装置发明 | 具体实施方式 | 装置布置 | 示意图 |
| 实用新型 | 具体实施方式 | 装置结构 | 结构图（件号） |
| 任何 | 附图说明 | 图索引 | 附图说明文字 |
| 任何 | 摘要 | 摘要附图 | 主流程图/主图 |
